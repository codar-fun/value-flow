# 社区货币 /「流动圈」

> 当前状态：第一版可运行网页已发布，数据库、业务接口和主要写入流程已经接通。
> 当前用途：产品验证与小范围测试，不是可直接面向真实社区开放的正式生产系统。
> “流动圈”“泡泡助手”仍是暂名。

线上地址：<https://liudong-circle-demo.helloworld-zoey.chatgpt.site>

## 先说最重要的边界

这个网址已经不是纯静态 Demo：创建圈子、发布需要或提供、发送好人卡、记录互助、修改公开设置和生成邀请都会写入 Cloudflare D1，并在刷新后保留。

但当前站点仍是公开访问，尚未接入正式身份体系。没有 Sites 身份信息的访问者会回退到示例用户 `qiaoye`，因此多人匿名访问时可能共同读写同一份测试数据。

在接好登录和成员身份前：

- 可以由项目所有者自己测试；
- 可以使用不敏感的虚构数据；
- 不要录入真实住址、健康、照料、经济困难或私人关系信息；
- 不要把当前链接当作正式社区入口大范围传播。

## 现在能做什么

- 从数据库加载成员、圈子、账户、动态与个人设置；
- 发布“我想要 / 我可以给”，并暂停或重新发布；
- 发送好人卡；
- 记录已经完成的互助，并同步更新双方余额；
- 当事人拒绝或撤销互助记录，恢复双方额度；
- 创建圈子，同时建立创建者成员关系、初始账户和规则；
- 生成 7 天有效、单次使用的邀请链接；
- 通过邀请落地页直接加入或提交管理员审批；
- 保存跨圈公开设置；
- 使用泡泡助手整理草稿并保存会话记录；
- 调用系统分享；
- 在未配置外部 AI API 时使用内置整理器。

## 静态 Demo 还在吗？

在，但目前没有单独的公开网址。

- 原静态版本源码保留在 Git 提交 `e3c3e28`；
- 原静态部署保留为 Sites 历史版本 8；
- 当前公开网址已经由可运行版本 9 覆盖；
- `app/demo-data.ts` 仍保留，职责变为首次初始化数据库的示例种子数据，不再是页面运行时的唯一数据源。

如果之后需要长期并排访问，建议把静态版本部署成第二个独立站点，例如“流动圈视觉原型”，而不是反复用当前生产网址切换版本。这样可以同时保留：

1. 不写数据、适合展示设计的静态原型；
2. 会写数据库、适合测试真实流程的运行版。

## 下一步做什么

按优先级建议：

### 1. 先确定身份与测试范围

- 决定短期测试使用 Sites 登录、邀请码身份，还是微信身份；
- 取消公开匿名访问者共用 `qiaoye` 的生产回退；
- 明确谁是圈子创建者、管理员、普通成员和未加入访客；
- 准备“重置测试数据”与“清空单个测试圈”的安全入口。

### 2. 接泡泡助手 API

填写模型接口地址、密钥和模型名。完整配置见 [`docs/后端与泡泡助手配置.md`](docs/后端与泡泡助手配置.md)。未配置时其他功能仍可运行。

### 3. 用 2—5 个真实测试者跑完整流程

至少验证：

- A 创建圈子并邀请 B；
- B 加入后发布需要；
- A 与 B 在线下完成互助；
- 任意一方记录并入账；
- 另一方修改或拒绝；
- 双方检查余额、公开范围和通知是否符合预期；
- 成员暂停、退出或要求删除数据时怎么办。

### 4. 补齐目前只有接口、界面还不完整的流程

- 管理员审批列表与通知；
- 交易“更正额度/故事”的完整表单；
- 圈子规则和参考物的后续编辑；
- 成员退出、数据导出和删除；
- 真实分享图或小程序码；
- 语音转写；
- 运营日志、备份与异常恢复。

### 5. 小范围验证后再决定微信化

先确认人们是否真的愿意发布、记录、拒绝和纠错，再决定做微信小程序、公众号登录或更复杂的运营后台。

## 本地运行

需要 Node.js 22 或更新版本。

```bash
pnpm install
pnpm dev
```

检查：

```bash
pnpm lint
pnpm test
```

泡泡助手本地配置：复制 `.env.example` 为 `.env.local` 并填写。真实密钥不要提交到仓库。

## 项目结构

```text
社区货币/
├─ app/page.tsx                 当前主界面与交互
├─ app/api/                     业务接口与泡泡助手代理
├─ app/join/[token]/            邀请落地页
├─ app/demo-data.ts             首次数据库初始化的示例数据
├─ db/schema.ts                 D1 数据模型
├─ db/runtime.ts                初始化、身份解析与数据查询
├─ drizzle/                     数据库迁移
├─ worker/                      Cloudflare Worker 入口
├─ docs/                        产品、技术与历史原型文档
└─ tests/                       构建与关键能力检查
```
