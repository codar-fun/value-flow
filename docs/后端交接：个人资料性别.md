# 个人资料性别

日期：2026-10-09。前端已接入，后端持久化和线上验收待确认。

- PATCH /me 支持 gender: male、female 或 null（清除选择），省略字段保留原值。非法值返回 400。
- 将字段保存到成员账号；历史账号默认为 null。
- /bootstrap 的 user、members、申请者 account，以及成员档案返回的账号对象携带 gender，使用同一枚举。
- 前端选择男／女／不显示；未选择不展示符号，不从头像或名字推断。
- 前端资料保存后回读 /bootstrap 核对性别；不一致保留编辑状态并显示错误。
- 验收：A 保存男后刷新仍为男；同圈 B 在动态、成员列表和档案见 ♂；改女见 ♀；清除后不显示；旧客户端省略字段不清空；退出重登仍保留。
