## 一、先聊社区：这里已经有什么

在谈社区货币之前，先看清楚社区里已经有哪些价值交换在发生。社区货币要做的不是重新发明一套东西——它是在已经存在的土壤上种一棵辅助的树。

### 1.1 社区中的四种价值交换

来自 Cohere 实验文件和俏也 LLM wiki 的交叉验证，社区里天然存在四种交换：

| 类型                     | 逻辑                          | 例子                   |
| ---------------------- | --------------------------- | -------------------- |
| **分享（Sharing）**        | 不求回报，不求被看见。「我的就是你的」         | 借工具、分享食物。「这个给你。」     |
| **礼物（Gift）**           | 反契约。回礼不能太对称，否则等于想两清。无限游戏    | 帮你搬家、送你一盆植物、陪你聊天     |
| **公共物品（Public goods）** | 捐献或公共资源，所有人都可以用             | 社区空间、共享厨房、公共图书       |
| ==**有成本的互助**==         | ==需要时间和精力，过于依赖市场交易，倡导内部流动== | 帮人修电脑、帮人搬家、长期照料、一次按摩 |

前三种——分享、礼物、公共物品——已经在运行了。它们不记账、不走货币、不需要系统。它们的热量来自关系和信任。

第四种——有成本的互助——恰恰是卡住的地方。它需要的信任比前三种高，但在稍微大一点的社区里，这种信任的可传递性很差。

### 1.2 礼物经济：社区的灵魂

俏也对礼物经济的理解是她做所有社区实验的哲学基础（LLM wiki 礼物经济概念页是最完整的记录）：

**定义**："我先给你，不期待回报；你如果给我，是因为你体验到给予的快乐。"

**核心特征**：
- 不是人情社会。"善有善报也不是有一个小人在记账。这些都是恐惧驱动。"
- 给和拿是放松的、不焦虑的、信任流动的
- 老挝僧侣布施是最生动的现场：给了就给了，没有谢谢，多余的再分出去
- 回礼不能太对称——别人送你西瓜你也还西瓜 = 你想两清 = 你想结束关系
- ==礼物经济是一个无限游戏==

**礼物经济在俏也的实践里**：
- 两年多不花住宿费——靠的是交换和互助
- 「赛博乞讨」——公开众筹腾讯会议会员，声明"你的布施是出于爱我"
- 分享会门票可交换代替付费
- CYC 社区免费入住

### 1.3 Graeber 的底层框架：人类经济 vs 商业经济

David Graeber 的《债：第一个 5000 年》（Debt: The First 5,000 Years）是对货币和债务最根本的重新理解。他用人类学和考古学证据推翻了一个流传两百多年的故事：==**货币不是从以物易物来的——是从「我欠你」来的。**== 真实的顺序是：信用（债务）→ 货币（作为记账单位）→ 现金交易。

在最早的苏美尔文明（公元前 3500 年），人们已经在使用复杂的信用体系。楔形文字泥板的大部分内容就是信用记录——A 欠 B 多少粮食，什么时候还。货币的出现不是为了方便交易，而是国家为了征税和维持军队而发明的。

**这意味着相互信用（mutual credit）不是社区货币的「创新」——它是人类经济最原始、最自然的形式。** 俏也在做的社区货币实验，本质上是在重新启用人类已经用了五千年的东西。

Graeber 提出了一个对我们至关重要的区分：

| | 人类经济（Human Economy） | 商业经济（Commercial Economy） |
|---|---|---|
| **货币的作用** | 重新配置人与人之间的关系 | 分配商品 |
| **货币类型** | 社会货币（social currency） | 商业货币 |
| **债务的性质** | 道德的、有弹性的「我欠你一个人情」 | 精确量化的「我欠你 100 元」 |
| **例子** | 彩礼、血债赔偿、和解礼物 | 超市结账、工资、贷款 |

Graeber 最深刻的洞察：==**社会货币不是用来「清偿」债务的——它恰恰是用来承认债务无法清偿的。**== 在某些部落里，杀人赔偿不是「付了钱就两清」，而是「付了钱表示我承认这笔债永远还不完」。

对社区货币的直接含义：
- ==社区货币不需要追求「账户归零」。券的存在本身就说明了「这个人给过」。它不是一个结算工具，是一个**承认工具**。==
- 社区货币走在一条极其狭窄的路上：==它需要一定程度的量化来让交换可见，但它不能跨过那条线——把关系变成算式。Graeber 给出了那条线的定义：**债务**（debt）可以被精确量化；**义务**（obligation）是道德的、有弹性的、不可量化的。社区货币的任务是让义务可见，但不把它变成债务。==
- 商业货币的核心操作需要暴力（或暴力的威胁）——把「我欠你一个人情」变成「我欠你 100 元」。社区货币的整个设计就是在拒绝这个转化。

### 1.4 何嘉的视角：社区的价值不只是钱

何嘉（大鱼营造创始人）的框架补充了一个关键视角：

> "如果我们把现金流比作动脉血，那非货币的价值交换就是静脉血。人有 30% 的动脉血，70% 的静脉血。"

社区里的六维资产——经济、物质、社会、智慧、文化、制度——大多数都不走钱的账。它们一直在流动，只是不可见。

礼物经济就是社区里最大的静脉血。它一直在循环，但你看不到它在流。

## 二、现有的交换有什么问题

礼物经济是好的。但它有几个结构性的盲区——不是礼物经济本身的问题，是它在一定规模下的局限性。

### 2.1 问题一：付出不可见

"我帮了你"——这件事只有你和我知道。社区不知道。==如果你帮了五个人，五次都是私下的，那在社区层面你就是「没有贡献」的人。这不是故意的忽视，而是**信息不流通**。==

何嘉把这个叫做「隐形劳动」——少数人反复承担打扫、整理、照料等看不见的工作，容易疲惫却得不到社区的看见。

### 2.2 问题二：给的人多，拿的人少

海德玛丽（无钱幸福作者）建立了完全基于礼物的 exchange circle，运行多年后最大的发现是：==**愿意给的人远多于愿意拿的人。**== 没有人好意思去接受帮助。给是快乐的，拿是羞耻的。

这导致的结果是流动卡住了：大家都在给，没有人接。礼物经济的循环断在「接受」这个环节。

### 2.3 问题三：信任不能传递（俏也的真实痛点）

> "有时候我的群里会出现一个人说'我想要 XXX'，但是因为她和大家不熟——她之前帮过我、她曾经为社区做过什么——但群里其他人不知道，她也不好意思说'我之前给过俏也东西'来证明自己。所以她的请求没人响应，这不公平。"

这个场景揭示了纯礼物经济最核心的盲区：==**礼物经济的记忆是私人的、分散的、不可传递的。**==

==俏也知道这个人帮过她。但群里其他人不知道。这个人的「贡献」在社区层面是不可见的，所以当她需要帮助时，没有社区层面的信任资本可以调用。==

如果这个人的贡献被记录过——哪怕只是「她被看见过」——情况就不同了。不需要精确数字，只是一个信号：**这个人在这里给过。**

## 三、社区货币的回应：两个圈，两种货币

免费圈和好人卡不是两个不同的地方——好人卡就是免费圈里接收者的一个可选动作。给予者不求回报、不求被看见，默认不记。但如果接收者觉得「这个人做的事值得被看见」，他可以自愿发一张好人卡。同一个圈，两种可能性。

核心是**按「谁来记」和「记了之后有没有债务」来区分**：

### 3.1 两个圈

```
免费圈（礼物经济）                         资源互助货币圈
不求回报，不求被看见                        有交换意义，需要记账
默认不记                                   发起人记
接收者可以自愿发好人卡                       有债务
无债务
                                         
"这个给你"                                "帮我搬家，我给你 X"
"谢谢你，我看到你了"（可选，自愿）
```

### 3.2 好人卡

本质就是分享、礼物经济——给予者不求回报、不求被看见。 但接收者如果愿意，可以在多发一个动作：**发一张好人卡。** 这不是义务——完全是自愿的。当接收者觉得「这个人做的事值得被看见」时，他可以主动给出这个信号。

**核心意义**：==好人卡纯粹用于表达感谢，表达「被看见」这件事。它和金钱没有任何关系——不能用来换任何东西。==就是一个信号。每次一张，需要说具体是什么事情。

**运作机制**：**接收者主动去记。** 这是整个设计里最关键的区别。给予者可能不想记——他给的时候就没想被记录，没想要回报。==但接收者感受到了什么，愿意给一个「看见的贴士」==。接收者给好人卡不产生任何债务——给予者不会因为收到了卡就欠了什么。

**债务关系：无。** 好人卡不会变成接收者的债务。它只是接收者觉得很好，愿意给一个看见的贴士。

**这和 social layer token 的关系**：鸡蛋说的「我知道你是一个好人，我给你发一个 token」——好人卡就是这个 token 的具体化。不是为了交换，而是为了标记和再分配。「这个人被看见过」= 值得被信任。

**好人卡解决了什么问题**：
- 它让无私付出的人被看见——**不需要付出者自己去请求认可**。接收者的主动性是核心。
- 它让信任可以流动——「这个人收到过 3 张好人卡」= 不管具体是什么事，至少有人觉得她值得被看见。当她需要帮助时，这个记录就是社区层面的信任资本。
- 它不制造债务——因为是接收者主动给的，接收者不欠任何人任何东西。这张卡只代表「我看见了」，不代表「我欠你」，也不用

**可以跨圈流动**：像是 reference letter，可以带到各个地方。

### 3.3 资源互助货币（有债务的交换货币）

==**核心意义**：用于做一些更重量的、能够标准化的事情，比如一个小时的打扫卫生、帮人搬家、修电脑。这些事情有一个明确的时间和精力成本，需要一个双方都认可的交换框架。==

==**运作机制**：**一般由发起人（被帮助的人）去记。** 是受帮助的那个人有义务去记——"你帮了我这个，我给你 X。"或者公开说「我需要帮助，付 X。」==这个动作本身就是对付出的承认和对交换的确认。

**债务关系：有。** ==资源互助货币创造了一个内部的债务关系——A 帮了 B，B 的账户 -X，A 的账户 +X。A 可以在未来用这个 +X 去请求别人的帮助。债务不是 B 欠 A 个人的——是 B 欠社区的。==这和 LETS 的 mutual credit 逻辑一致。

**资源互助货币解决了什么问题**：
- 它让「有成本的互助」有了一个公平的交换框架——不需要双方反复掂量「这个忙值不值得帮」。
- ==它提供了「请求许可」——有券在手 = 「我可以开口请求帮助」，这是海德玛丽说的那个社会许可。==
- ==它让社区知道「谁得到了帮助」——负余额不是坏事，它在说「社区正在照顾这个人」。==

**不可以跨圈流动**：因为债务是成员和社区之间的，**所以必须是社区成员**。

**社区可以作为主体**：社区可以请求大家帮忙，并有常驻可以换的等价物（一顿饭，一晚床位）。

### 3.4 两个圈之间的关系

|                | 好人卡/小红花         | 资源互助货币      |
| -------------- | --------------- | ----------- |
| **记不记**        | 默认不记。接收者可自愿发好人卡 | 记           |
| **谁记**         | （如发卡）接收者主动      | 发起人/被帮助的人   |
| **有没有债务**      | 无               | 有           |
| **能不能花**       | 好人卡不能花。纯信号      | 能花。是交换媒介    |
| **囤积**         | 囤积无意义，不能花       | 需要鼓励流动      |
| **对应 Graeber** | 社会货币：承认债务存在     | 社会货币：辅助债务流通 |

### 3.5 这个框架解了什么


完整图景：

| 圈 | 记不记 | 谁记 | 债务 | 例子 |
|------|--------|--------|------|------|
| 免费圈 | 默认不记。接收者可自愿发好人卡 | （如发卡）接收者主动 | 无 | 借工具、分享食物、「这个给你」。接收者觉得好 → 发一张好人卡 |
| 资源互助货币 | 记 | 发起人/被帮的人 | 有 | 「帮我搬家，给你 X」 |

## 四、让价值留在社区，不用金钱交易——一个需要诚实面对的张力

俏也的核心愿望：**让很多价值留在社区，不是对外交换。大家可以不用金钱去交易。**
这个愿望和好人卡 + 资源互助货币的框架是完全兼容的——两者都不和金钱锚定，都在社区内部流通。

但有一个需要诚实面对的张力：

**越清洁，范围越小；范围越大，越难避免和金钱接触。**

- 如果资源互助货币只用于**纯劳动和时间**（帮搬家、修电脑、陪聊天），它可以完全不涉及金钱。但这样的交换种类是有限的。
- ==一旦涉及**实物**（材料、工具、食材、交通费），就需要金钱参与——藤野万屋的答案是混合支付：社区货币付劳动力，日元付材料成本。但这就意味着货币圈和现金圈有一个接口。==
- 如果范围太小（只能换到几种服务），出口问题就会显现——赚了券花不出去 → 挫败 → 退出。

这不是一个需要现在解决的矛盾，而是一个需要被意识到的**结构性张力**。它没有完美的答案——只有不断调试的平衡点。可能的方向：

1. **开始时接受范围小**。先让资源互助货币在 10 个人的圈子里只交换纯劳动——帮搬家、修电脑、陪护。接受「券能买到的东西不多」。等流动起来了，再自然扩展到需要材料成本的服务（混合支付）。
2. **用好人卡补资源互助货币的覆盖盲区**。有些东西不适合量化交换（陪伴、情绪支持、社区融入），但它们值得被看见——好人卡就是用来记录这些的。
3. **让「不用金钱」成为一个倡导方向而非绝对规则**。Co 券方案的判断口诀是「如果你觉得对方服务能轻易在市场上出售 → 用钱」。这意味着有些交换天然更适合用钱——接受这个边界，反而让社区货币在自己擅长的领域更干净。

## 五、社区货币解决不了什么

诚实地说清楚边界，比说得它很好更重要。

### 5.1 没人用

最现实的风险。发行了券但大家不花也不收——藤野万屋每天 5-10 条需求，也不是每条都成交。

此外还有一个**密度问题**：藤野万屋 500 人每天 5-10 条需求。如果俏也的第一个实验是 10 个人，可能一个月才有一次交换。券长期闲置，系统感觉不到活力。太小也会死。

**缓解方向**：==初期在很小的圈子里试，但选人时不只是「谁愿意参与」，更要考虑「谁真的有需要、谁能帮到谁」==——确保初始群体有真实、频繁的互助需求。好人卡可以比资源互助货币更早启动——它不需要「交换匹配」，只需要有人愿意表达感谢。

### 5.2 有人就是不参与

海德玛丽花了十几年没解决的问题。有好卡和互助货币都不能强迫一个人觉得自己有资格请求。仍然会有人囤着券不用、或者根本不用。好人卡的设计通过「接收者主动记」部分缓解了这个问题——它不需要「拿」的人做任何事，只需要「给」的人愿意表达感谢。

### 5.3 可能加剧不平等

Cohere 实验文件明确列出：社区货币可能导致马太效应。本来就活跃、有技能、善表达的人赚更多券；本来就边缘的人更难参与。好人卡可能部分缓解这个问题——它是接收者主动给的，被动的人也可能收到。

### 5.4 可能加剧隐形燃烧

何嘉描述的危险：如果「有券」让付出者更难拒绝新的请求——"因为你收了券所以你该做"——那就做反了。资源互助货币需要明确：收了券 = 完成了这一次交换，不代表承诺下一次。

### 5.5 不能替代信任建立

一个陌生人即使有 3 张好人卡和 10 张互助券，大家仍然不认识她。券降低请求门槛，但不替代人和人的直接接触。==**藤野万屋入会时必须当面听说明**==，信任所需的**社会摩擦**。

在俏也的微信群里，新人的第一接触是什么？一个群公告？一个共享文档？还是有人私聊解释？**这个接触点的设计会直接影响新人是否真的理解「这不是钱」。**

### 5.6 出口问题：券能买到什么

一个人赚了互助券，她能拿券换到什么？如果只能换「社区里其他人的服务」，当她需要一个实物（灯泡、药、食材）时，券就没用了。

藤野的混合支付方案（社区货币付劳动力 + 日元付材料成本）是一个方向。但这意味着资源互助货币圈和现金圈不是完全隔离的——有些交换需要同时用两种媒介。

三个场景分别的「出口」：
- 场景 A（个人圈）：俏也提供的东西（咨询？活动优先权？zine？）
- 场景 B（共学）：共学内部其他人的服务
- 场景 C（线下社区）：实物共享 + 工具借用 + 空间使用权

## 六、怎么设计：机制、原则、场景

### 6.1 核心机制

**两种货币，两条平行系统**：

**好人卡（无债务的看见货币）**：
- 接收者主动发——"谢谢你，我看到你了"
- 不创造债务。不用于交换。纯粹的信号
- 不需要过期、不需要流通速度——它就是静态的「被看见」的证据
- 不需要防囤积——囤积好人卡没有意义（不能花），但收到很多张本身就说明了什么

**资源互助货币（有债务的交换货币）**：
- mutual credit 模型：A 帮 B → A +N，B -N
- 不要求储备金，信用在交易中共同创造
- 负余额不是「欠钱」，是「你被社区帮助了」
- 需要鼓励流动——过期/demurrage 可以考虑
- 和 LETS 逻辑一致：交易本身创造货币

**关于「鼓励负债」需要特别注意**：这不能只是一个原则——它需要一个**文化装置**。藤野万屋的文化装置是「负数的人激发出了本地区擅长的事情」——用叙事重新定义了负债。俏也的社区需要自己的文化装置。

**多货币**：==每个人/每个组织都可以创建自己的货币。==**但第一个实验建议只跑资源互助货币 + 好人卡这两种。** 让它们在 10 个人里跑三个月，看看会发生什么，再谈更多的货币类型。

**以俏也为中心，慢慢加人**：
1. 俏也的个人货币（活动交换、免费住宿 credit）
2. 在群里运行（大家写 offer/need，共享表格或小程序记录）
3. 有人觉得好用，申请开通自己的货币

**关于「俏也为中心」的结构性问题**：这是最务实的起步方式，但它制造了单点依赖。藤野万屋独立于创始人运行了 16 年——它做到了去中心化。这不是现在要解决的问题，但值得标注。

### 6.2 设计原则

1. **不被异化**：数字是影子，关系是实体
2. **不替代善意**：不是把礼物经济变成记账。纯分享不记
3. **不与金钱锚定**：价值来自社区内部约定。让价值留在社区
4. **不追求归零**：负余额不是坏事。社会货币不是用来清偿债务的，是用来承认债务存在的
5. **小而密**：越小越有意义，但注意密度——需要足够的交换频次
6. **接收者记，给予者不记**：好人卡的核心原则。接收者主动给，保持礼物经济的纯粹
7. **鼓励流动**（资源互助货币）：花出去，不是存起来
8. **两个圈各安其位**：免费圈默认不记（接收者可自愿发好人卡）/ 资源互助货币发起人记

### 6.3 三个使用场景

**场景 A：俏也个人交换圈**
- 别人给俏也免费住宿/帮忙 → 俏也发好人卡或互助券 → 可在圈内换东西
- 不能兑换钱、不能转让圈外人
- **「对我有什么好处」的答案**：持有俏也币 = 被邀请进入俏也的内圈 = 优先参与活动/交换

**场景 B：做人共学**
- 付费进入 → 获得初始互助券 + 好人卡可用额度
- 内部互相购买服务 → 悬赏/许愿/打赏
- 不提现、不对圈外流通
- **「对我有什么好处」的答案**：有互助券 = 可以在共学里请求别人的帮助，不需要等到和别人混熟

**场景 C：线下常住社区**
- 藤野万屋模型 + 好人卡：给你/给我清单、价格双方商量、负余额不污名
- 好人卡用于日常看见和感谢
- **「对我有什么好处」的答案**：日常互助被记录 → 当你需要帮助时，你的记录就是你在这里「被看见」的证明

### 6.4 数字化 vs 纸质

纸券的好处：触感、仪式感。纸券的坏处：容易丢、需要物理在场、英国本地货币的教训已经证明纸币在 2020 年代会死。

数字记录的好处：方便、可追溯、不依赖物理在场。数字记录的坏处：冷、像银行 app、「只是一个数字」。

**建议**：好人卡用数字（微信群里的简单记录），因为接收者主动给，不需要物理交换。资源互助券可以用数字 + 线下的混合——主要记录在共享文档，偶尔线下见面时用实物券增加仪式感。

## 七、参考案例的核心教训

### 7.1 成功的案例

**藤野万屋（相关性 ★★★★★）**
- 纸存折 + 双方签名 + 「给你」「给我」的语言框架
- 「负数的人激发出了本地区擅长的事情」——负余额的文化设计
- ==入会时必须当面听说明，确保理解「这不是钱」==
- 据二手整理，约 350 个家庭/500 名会员，邮件组每日约 5–10 条需求（精确数字待核原始来源）

**LETS（相关性 ★★★★）**
- Sophie 的故事（来自 Sydney LETS 的自述）[Sydney LETS](https://sydneylets.org/)：账户负了两年，系统选择包容。这是一个有力的伦理叙事，说明"看具体处境"比规则更重要——但不能替代所有成员的额度、退出与共同损失规则
- 交易内容都是平时不会用钱买的东西

**无钱幸福 / 海德玛丽（相关性 ★★★★）**
- 完全退出货币系统 20+ 年。给的人多、拿的人少
- 好人卡直接回应了她的核心困境——通过接收者主动记，让「被看见」不需要「拿」的人主动开口

**Fureai Kippu（相关性 ★★★★）**
- 照顾老人赚时间信用。==有观察显示老人更愿意接受 Kippu 照顾者而非日元付费者==——但相关研究提醒该系统复杂、效果难以评价，不应过度概括为普遍规律。[Hayashi, 2012](https://doi.org/10.15133/j.ijccr.2012.003)

**social layer token（来自 flomo，相关性 ★★★★）**
- 鸡蛋的实验："我知道你是一个好人，我给你发一个 token，之后大家都会知道你是一个好人"——这是好人卡最接近的前身

（详细分析见 `参考案例-详细版.md`）

### 7.2 失败的案例：英国本地货币为什么停运了

> ⚠ 以下案例均为与法币 1:1 锚定、面向零售商户的本地货币。它们的失败原因不一定直接适用于互助型、非现金、封闭的社区实验。保留为工作假设而非因果证明。

| 货币                  | 存活期       | 停运原因                              |
| ------------------- | --------- | --------------------------------- |
| Totnes Pound        | 2007–2019 | 无现金社会趋势，纸币使用下降（[BBC 报道](https://www.bbc.co.uk/news/uk-england-devon-47471231)）；被游客当纪念品囤积   |
| Bristol Pound       | 2012–2021 | 常务董事 Diana Finch 接受采访时表示无法回答"what's in it for me"（[Wired 报道](https://www.wired.com/story/local-currencies-dead)）；被评价为 "middle class and twee" |
| Brixton Pound       | 2009–2021 | 迁移到加密货币（换了一种存在方式）               |
| Exeter Pound        | 2015–2018 | 未能达到足够规模                           |
| Lake District Pound | 2018–2020 | 同上                              |

**值得注意的教训**（不直接外推到本项目的互助场景）：

1. **纸币在 2020 年代会死。**

2. **供应端断裂。** 商家收到了本地币但批发商不接受。俏也不面向商家，但「出口问题」是相同结构的不同表现。

3. **囤积比想象中严重。** Totnes Pound 被游客买走贴在冰箱上。但好人卡天然免疫这个问题——它不能花，囤积没有意义。

## 八、礼物经济与社区货币的关系：再退一步看

> 社区货币是影子，不是光源。

==礼物经济已经在那里了——分享、给予、互助、信任。它们是光。社区货币只是让这些光投下影子——让原本就存在的流动变得可见。==

Graeber 的框架给这个隐喻加了厚度：**社会货币不是用来清偿债务的，是用来承认债务存在的。**

==好人卡是这个洞察最纯粹的体现——它不用于交换，不创造债务，只是「我看到你了」。接收者主动记，给予者不需要请求被看见。影子不是给予者自己投的，是接收者投的。==

==资源互助货币则进一步——它让「债务」在社区内部流通起来。但它的基础仍然是 Graeber 的逻辑：不是清算，是承认和流动。==

**关键提醒**：==当社区成员开始习惯看影子而不是光——开始觉得「没有记录的就不算」——那社区货币就已经越界了。纯分享区需要被持续地维护和示范。俏也和核心成员需要持续展示「不记我也帮你」。==

## 九、风险清单

> 不需要现在全部解决，但需要在实验中被持续关注。

**运行风险**：
- 没人用（最现实的）
- 密度太低——10 个人一个月没有一次交换
- 好人卡没人发——接收者不主动，系统空转
- 用了几天停了
- 俏也作为枢纽的单点依赖

==**形式** 最好是小程序，发一张微信聊天截图给它，或者说一段话，就可以确认记录？==
==小程序里可以写供需？（还是供需在微信群里？）==

**设计风险**：
- 量化异化：特别是资源互助货币，数字可能逐渐定义价值
- 马太效应：活跃的人赚更多
- 社交压力：余额变成比较和焦虑
- 侵蚀纯分享区：货币逻辑逐渐成为默认
- 好人卡和互助货币的概念混淆——有人把好人卡当货币用

**结构性风险**：
- 隐形燃烧加剧：收了互助券反而更难说「不」
- 权力集中：谁发卡、谁管记录
- 「清洁 vs 有用」的张力——越不和金钱接触范围越小
- 出口堵塞：赚了券花不出去 → 退出

## 十、怎么知道它在变好还是变坏

**好的信号**：
- 有人主动给别人发了好人卡——接收者在主动记
- 有人用互助券请求了帮助——券被当请求许可在用
- 有人免费帮了别人但没收互助券，只收到了好人卡——纯分享区活着
- 有人用互助券从一个陌生人那里换到了帮助——信任在传递
- 有人把自己的互助券给了另一个人——赠予行为出现了
- 好人卡和互助券被当成两种不同的东西在用——概念区分清晰

**坏的信号**：
- 大家开始问「这个值几张互助券？」——开始精确量化
- 只有固定几个人在用——形成了券圈
- 「我帮了你，你该给我互助券」成为默认期待
- 所有人都账户为正——没人敢花
- 有人把好人卡当成互助券来讨价还价——概念混淆了

## 十一、待讨论

1. **第一个实验在哪做？** 俏也个人群？做人共学？线下社区？

2. **好人卡和互助券的物理/数字形态**：好人卡用微信群记录？互助券用共享表格？需要两种不同的呈现方式吗？

3. **负余额的文化叙事**：用什么话来定义「负债」不被污名化？"负数的人激发了本地区擅长的事情"（藤野）——俏也的社区用什么？

4. **新人 onboarding**：第一个接触是什么？怎么让人理解「这不是钱」和「好人卡和互助券是两种东西」？

5. **出口问题**：三个场景的「券能买到什么」逐一明确

6. **「清洁 vs 有用」的取舍**：开始时接受范围小（只交换纯劳动），还是允许混合支付（互助券 + 现金付材料成本）？

7. **锚定还是不锚定？** 互助券要不要有时间参照（如 1 券 ≈ 30 分钟）？

8. **要不要 demurrage？** 互助券需要过期吗？

9. **俏也的枢纽角色能持续多久？**
