# 流动圈：当前上线版本的功能介绍

- 版本基准：前端 `main`（`fd59162`），生产 `https://flow.sola.day`，后端 `https://flow-api.sola.day/api`
- 整理日期：2026-10-02。**内容以代码与生产实测为准，不是设计稿。**

## 0 这是什么

一个给小圈子用的互助记账工具：记录谁帮了谁，用圈子自己的额度记下来，不做排名、不换钱。

产品自己写在「了解我们」里的四条底线：

- 不与人民币兑换
- 不做贡献排名
- 可以不记录
- 可以拒绝、暂停或离开

---

## 1 登录

| 项 | 现在的行为 |
|---|---|
| 方式 | **邮箱验证码**，没有密码 |
| 流程 | 输入邮箱 → 收 6 位验证码 → 验证 → 首次登录要「给自己取个名字」 |
| 会话 | 浏览器 cookie 保持登录；刷新不掉；退出会清掉 |
| 临时故障 | 数据服务连不上时页面顶部出现重试条，**不会把你登出**，点「重试」即可 |
| 已知未知 | 验证码的有效期、重发规则、限流、邮件送达率**没有对外承诺**（BE06 未取得证据）。真机测试里如果有人收不到邮件，这是首要观察项 |

## 2 五个页面（底部导航）

| 页面 | 作用 |
|---|---|
| **动态** | 你加入的圈子里发生的事：互助记录、需要/提供、好人卡，按时间倒序；可按「全部 / 互助记录 / 只看需要 / 只看提供 / 好人卡」筛选 |
| **发现** | 跨圈看别人发布的需要与提供；「可加入的圈子」列出你还没加入的圈子，可直接加入或申请 |
| **记录** | 打开记一笔（默认停在「记一笔」，可切到我想要 / 我可以给 / 好人卡） |
| **圈子** | 当前圈子：记一笔、邀请成员、圈子介绍、成员、圈子设置（仅圈主） |
| **我的** | 个人档案、好人卡数量、我的需要/提供、我的圈子与余额、分享档案、编辑资料、公开设置、退出登录 |

顶部还有：铃铛（通知）与右上角入口。

## 3 圈子

### 3.1 创建（四步）

1. **基础**：圈名、一句话介绍、图标
2. **额度**：这个圈子的额度叫什么（默认「积分」），以及协商参考
3. **治理**：新成员怎么加入 ——「受邀直接加入」或「管理员审批」；圈子约定（一行一条，最多 10 条，例如"可以开口，也可以拒绝"）
4. **确认**：创建前预览，包括允许负余额、是否需对方确认、协商参考

### 3.2 加入方式

| 方式 | 说明 |
|---|---|
| 邀请链接 | 圈主生成，**7 天有效、仅可使用 1 次**；点开先登录，登录后自动加入 |
| 微信邀请图 | 生成一张带二维码的海报（含圈名），可保存图片或直接系统分享；扫出来就是邀请链接 |
| 发现页自助 | 「发现 → 可加入的圈子」里点「加入 →」（直接加入圈）或「申请 →」（审批圈，等圈主放行）；申请可撤回 |

> ⚠️ **隐私提示**：发现页对所有已登录用户可见，会露出圈名、一句话介绍、成员数与额度名。不想被陌生人看到就用邀请链接。

### 3.3 圈内

- **成员**：查看成员、余额、待放行申请；圈主可「通过 / 谢绝」
- **邀请成员**：生成链接或海报
- **圈子介绍**：约定、规则
- **圈子设置**（圈主）：允许负余额、记录需对方确认、允许拒绝或更正、协商参考、约定
- **转让圈主**：圈主可把圈子转给别人；转让后旧圈主不再有审批权限
- **退出圈子**：有未结清额度或是圈主时会被拒绝（需先转让）

## 4 记一笔（互助记录）

| 字段 | 说明 |
|---|---|
| 圈子 | 有多个圈子时可选记在哪个圈 |
| 对方 | 选择一位成员 |
| 方向 | 「对方帮了我」/「我帮了对方」 |
| 额度 | 数字，最小 1，单位是本圈额度名 |
| 一句话标题 | 最多 60 字，例如「厦门借住一晚」 |
| 发生了什么 | 可选，一段故事 |
| 让谁看见 | **圈内公开** / **神秘记录**（其他人只见到"一笔互助"，不显示是谁）/ **私密记一笔**（仅当事人） |

提交前有一次「查看草稿」确认步骤，可返回修改。

**额度与账本**：每个成员在每个圈子里有 `余额 / 给出 / 收到` 三个数。给的人 `+`，收的人 `-`。

**重复提交保护**：每份草稿带一个幂等键，网络重试不会记两次（不带键的裸请求仍会产生两条，这是后端的定义）。

---

## 5 待确认 / 更正 / 撤销

取决于圈子的两项设置：**记录需对方确认**、**允许拒绝或更正**。

| 动作 | 谁可以做 | 结果 |
|---|---|---|
| 确认 | 只有**对方**（记录发起人自己确认会被拒绝） | `pending → confirmed`，此时才入账 |
| 提议更正 | 任一方（在允许更正的圈子里） | 记录进入"待处理更正"状态，对方看到提议的新额度 |
| 接受 / 谢绝更正 | 被提议的一方 | 接受 → `corrected`，按新额度入账；谢绝 → 回到原状 |
| 撤销 | 发起人 | `→ rejected`，双方额度**全额回滚**；重复撤销不会重复回滚 |

**撤销后的可见性**（后端 2026-10-01 修复）：撤销的那条记录**只有当事人双方**还能看到，档案里显示「已撤销」；同圈第三人和动态流里都不再出现。

## 6 需要 / 提供（发布）

两种：**我想要**（粉色）/ **我可以给**（绿色）。

字段：标题、完整说明、时间（选填）、地点（选填）、参考额度（选填）、在哪些圈子里出现、是否**跨圈公开**。

状态与操作：

| 状态 | 含义 | 可做的操作 |
|---|---|---|
| 进行中 | 正常展示 | 暂停 |
| 已暂停 | 别人暂时看不到 | 重新发布（内容原样恢复） |
| 已结束 | 关闭 | — |

> **内容发布后不能修改。** 要改就暂停旧的、重新发一条。这是已确认的产品决定（BE09），界面上不会额外提示。

跨圈公开的内容会出现在你加入的所有圈子里，也会被「发现」页的人看到。

---

## 7 好人卡

给某个成员发一张卡片，写一段「发生了什么」。

- **跨圈公开，跟着 TA 走**：出现在对方档案里，跨圈可见
- **只给对方看**：仅当事人与接收者可见

好人卡不计入额度账本。

---

## 8 通知

铃铛显示未读角标，点开是通知列表。类型包括：

| 类型 | 触发 |
|---|---|
| 收到了一笔互助 | 对方记了一笔关于你的记录 |
| 待你确认 | 需要你确认的记录 |
| 更正提议 / 更正结果 | 对方提议改额度、或已处理 |
| 记录被撤销 | 对方撤回了某笔记录 |
| 入圈申请 / 邀请 | 有人申请加入你的圈子，或被处理 |

记录类通知都带目标记录 id，点开会跳到你的「互助记录」并**定位、高亮到那一条**。

---

## 9 个人档案与分享

- **档案**：头像、名字、handle、一句话介绍；数量统计（好人卡 / 需要·提供 / 互助记录）；三个 tab 可翻
- **编辑资料**：改名字、介绍、头像（可随机换一套搭配）
- **分享档案**：生成一张个人档案海报，可保存图片或走系统分享。只放跨圈公开的内容，圈内内容不会印在海报上
- **公开设置**：好人卡是否公开、需要/提供是否公开、私密好人卡是否保持私密

**联系方式（如微信号）只对同圈成员可见** —— 非成员与待审批的人拿到的是空值，这是服务端过滤，不是前端隐藏。

## 10 现在的边界（真机测试可顺带验证）

| 项 | 现状 |
|---|---|
| 发布内容编辑 | 不支持，暂停 + 重发（已决定不做） |
| 未登录邀请预览 | 看不到是谁邀请、进哪个圈（已决定不做） |
| 数据导出 / 账号删除 | 无自助能力，需人工处理 |
| 验证码邮件 | 送达时间、垃圾箱、限流规则未验证 |
| 真机相关 | 相机扫码识别率、微信内置浏览器、图片保存、系统分享、软键盘遮挡 —— 均未测 |
| 备份 | 有持续备份，但**恢复演练、告警接收人、发布回退流程**未落实 |
