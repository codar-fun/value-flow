# 流动圈：后端与前端集成

> 更新日期：2026-08-21
> 前端分支：`codex/value-flow-sync`

## 1. 权威边界

loop-backend 是用户身份、membership、圈主权限、余额、互助记录、需要 / 提供、好人卡、邀请、通知和设置的唯一权威。

前端不保存独立业务账本，也不根据可见记录重算余额。`db/runtime.ts` 名称来自历史架构，现在只把 `/bootstrap` 响应转换成前端类型。

## 2. 运行配置

默认后端：

```text
LOOP_API_BASE=https://loop-api.sola.day/api
```

浏览器只请求当前站点的 `/api/*`。route handler 在服务端调用 loop-backend，避免 CORS，并把 token 保存在 httpOnly cookie。

生产前端由 `ginger.yml` 中的 `flow-circle` 服务发布到 `https://flow.sola.day`。`.openai/hosting.json` 只保留为当前构建所需的逻辑 binding 配置，不再作为发布目标。不得把本地 test auth 变量写入生产 secrets。

## 3. 身份流程

```text
POST /api/auth/request
→ POST /api/auth/verify
→ 首次账号 POST /api/auth/profile
→ GET /api/bootstrap
```

生产没有匿名身份回退。退出登录会清除 access / refresh cookie。

### 本地测试认证

本地可通过 `.dev.vars` 开启 A/B/C 测试用户按钮，但必须同时满足：

- `NODE_ENV` 不是 `production`；
- `LOCAL_TEST_AUTH=true`；
- `LOOP_API_BASE` 是 `localhost` / `127.0.0.1` / `::1`；
- 每个测试用户使用本地 loop-backend 真实签发的 access token。

这只绕过 OTP 输入，不绕过 authorization。不能伪造前端身份、接受任意验证码，或对生产后端启用测试入口。

## 4. 资料与头像

`PUT /api/profile` 映射到 loop 的 `PATCH /me`，可写入昵称、简介、同圈联系方式和 avatar 字符串。

头像字段允许 8 个抽象系统头像枚举，或 `custom2:` 开头的定制人物组合。新账号后端 avatar 为空时，前端根据 account ID 稳定选择一个系统头像；用户保存后才写入后端。旧版头像中的 accessory 值仍可解析，但当前界面不提供也不渲染右下角标记，新保存统一写为 `none`。

## 5. 互助记录状态和责任

前端支持创建、确认、提议更正、接受 / 拒绝 / 撤回更正，以及拒绝 / 撤销记录。额度入账、差额调整和冲销全部由 loop-backend 完成。

前端把：

```http
PATCH /api/transactions/:id
{"action":"reject"}
```

映射为：

```http
PATCH /records/:id
{"action":"reject"}
```

后端必须在一个数据库事务中同时处理记录状态和双方账户；同一个 action 重试时还需要幂等。

## 6. 已修复的 P1

```text
pending → confirmed(4) → corrected(6) → rejected
```

撤销逻辑只把 `confirmed` 当作"已入账"，`corrected` 被漏在状态集合之外，因此记录状态改了、双方账户没有冲销。后端已改为按明确的已入账状态集合（`confirmed` + `corrected`）判断，并按记录当前有效金额在同一事务内反向更新 `balance` / `given` / `received`。

2026-08-21 已在生产验证：`confirmed(4) → corrected(6) → rejected` 后双方归零，重复撤销返回 422 且不再二次冲销。测试遗留的 `75f10b1a-97d7-425c-bf30-9f7f97be23cb` 及其 `+6/-6` 残值也已清零。

复现证据和回归用例见 [`后端问题：已更正记录撤销后余额未回滚.md`](后端问题：已更正记录撤销后余额未回滚.md)。

## 7. 当前明确不接入

- 前端泡泡助手；
- AI 图片识别或聊天截图识别；
- 语音转写；
- 跨圈额度兑换、排行榜和信用分。

不要因为 loop-backend 保留某个草稿接口，就把它当作当前产品已经实装的能力。
